# legacy-expo

Código fuente de la app Expo/React Native anterior a la migración a Kotlin nativo.

**Solo referencia.** No instalar dependencias ni ejecutar en local salvo que necesites consultar o comparar implementaciones.

- No ejecutar `npm install` en el portátil de desarrollo (ocupa ~400 MB).
- No usar `expo run:android` ni compilar APKs localmente.
- Las builds activas están en la raíz del repo (Kotlin) y se generan en GitHub Actions.
